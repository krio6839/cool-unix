# 蓝牙数据上传接口文档

---

## 接口1：上传实时数据


**请求方式：** POST

**Content-Type：** application/json

**请求参数：**

```json
{
  "data": [
    {
      "id": "m0abc123",
      "timestamp": 1714358400000,
      "type": "heartRate",
      "value": 72,
      "ppi": 850
    },
    {
      "id": "m0abc124",
      "timestamp": 1714358410000,
      "type": "bloodOxygen",
      "value": 98,
      "ppi": null
    }
  ]
}
```

**请求字段说明：**

| 名称             | 类型    | 必填 | 说明                                    |
| ---------------- | ------- | ---- | --------------------------------------- |
| data             | Array   | 是   | 实时数据列表                            |
| data[].id        | String  | 是   | 数据唯一标识                            |
| data[].timestamp | Integer | 是   | 时间戳（毫秒）                          |
| data[].type      | String  | 是   | 数据类型：heartRate/bloodOxygen/battery |
| data[].value     | Number  | 是   | 测量值                                  |
| data[].ppi       | Integer | 否   | 心率变异性（仅心率数据有）              |

### 响应示例

```json
{
  "code": 0,
  "msg": ""
}
```

### 响应字段说明

| 名称 | 类型    | 说明             |
| ---- | ------- | ---------------- |
| code | Integer | 响应代码，0=成功 |
| msg  | String  | 错误信息         |

## 接口2：上传睡眠数据


**请求方式：** POST

**Content-Type：** application/json

**请求参数：**

```json
{
  "data": [
    {
      "id": "sleep001",
      "reportTimestamp": 1714358400000,
      "bedtime": 1714339200000,
      "sleepTime": 1714342800000,
      "wakeTime": 1714375200000,
      "getupTime": 1714377000000,
      "recordCount": 480,
      "statuses": [
        { "minuteIndex": 0, "status": 2 },
        { "minuteIndex": 1, "status": 2 },
        { "minuteIndex": 2, "status": 1 }
      ]
    }
  ]
}
```

**请求字段说明：**

| 名称                          | 类型    | 必填 | 说明                                 |
| ----------------------------- | ------- | ---- | ------------------------------------ |
| data                          | Array   | 是   | 睡眠数据列表                         |
| data[].id                     | String  | 是   | 睡眠记录唯一标识                     |
| data[].reportTimestamp        | Integer | 是   | 报告生成时间戳                       |
| data[].bedtime                | Integer | 是   | 入睡时间戳                           |
| data[].sleepTime              | Integer | 是   | 实际入睡时间戳                       |
| data[].wakeTime               | Integer | 是   | 醒来时间戳                           |
| data[].getupTime              | Integer | 是   | 起床时间戳                           |
| data[].recordCount            | Integer | 是   | 记录条数                             |
| data[].statuses               | Array   | 是   | 睡眠状态列表                         |
| data[].statuses[].minuteIndex | Integer | 是   | 分钟索引                             |
| data[].statuses[].status      | Integer | 是   | 睡眠状态：0-清醒/1-REM/2-浅睡/3-深睡 |

### 响应示例

```json
{
  "code": 0,
  "msg": ""
}
```

### 响应字段说明

| 名称 | 类型    | 说明             |
| ---- | ------- | ---------------- |
| code | Integer | 响应代码，0=成功 |
| msg  | String  | 错误信息         |
