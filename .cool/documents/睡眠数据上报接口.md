## 0. 两个接口的职责

| 接口                 | 承担                                                       | 数据来源                                                         |
| -------------------- | ---------------------------------------------------------- | ---------------------------------------------------------------- |
| `POST /upload/ppi`   | **睡眠详情**（逐秒分期曲线）+ 心率/血氧/PPI + 广播其余字段 | 设备每秒一条：广播 `0x50` 1 Hz + 生命体征历史 `0x3A/0x3B` 补缺秒 |
| `POST /upload/sleep` | **睡眠摘要**（入睡/醒来时刻 + 三段时长 + 静息心率）        | 设备睡眠事件 `0x3C/0x3D` 的 `SleepResult`，一晚一条              |

睡眠详情不再由睡眠接口提供：设备事件里只有 `2 个时刻 + 3 个时长`，画不出逐秒曲线；
曲线只能来自设备每秒的 `status`。

## 1. `/upload/ppi`

```json
{
	"device": "BOOM-0001",
	"address": "AA:BB:CC:DD:EE:FF",
	"timezone": "08:00",
	"datas": [
		{
			"time": "2026-10-08 02:13:07",
			"hr": 62,
			"spo2": 950,
			"ppi": 980,
			"activity": 1,
			"behavior": 0,
			"ppgAttached": 1,
			"bhr": 55,
			"steps": 5123,
			"calorie": 1234,
			"rmssd": 42.5
		}
	]
}
```

| 字段          | 说明                                                                                   | 历史补录秒 |
| ------------- | -------------------------------------------------------------------------------------- | ---------- |
| `time`        | 该秒时间，按 `timezone` 格式化。秒值本身来自设备（广播 `utc` / 历史 `startSec`）       | 有         |
| `hr`          | 心率 bpm，设备原始值                                                                   | 有         |
| `spo2`        | 血氧，**设备原始值（×10）**：`950` = 95.0%。⚠️ 口径已改，见 §3.1；`0` = 这一秒设备没给 | `0`        |
| `ppi`         | 脉波间期 ms，设备原始值                                                                | 有         |
| `activity`    | 设备 `status` 的低 3 位，**睡眠详情就是它**，见下表                                    | 有         |
| `behavior`    | 设备 `status` 的 bit5-3，行为类型，见下表                                              | 有         |
| `ppgAttached` | 设备 `status` 的 bit6，PPG 佩戴：`1` 佩戴 / `0` 未佩戴                                 | 有         |
| `bhr`         | 静息心率 bpm（`basal heart rate`）                                                     | `null`     |
| `steps`       | **当日累计步数**，不是增量                                                             | `null`     |
| `calorie`     | **当日累计运动卡路里 ×100 kcal**（`1234` = 12.34 kcal），不是增量                      | `null`     |
| `rmssd`       | RMSSD，单位 ms，设备 float32 原值。是设备滑动窗口算出来的，不等于「这一秒的 HRV」      | `null`     |

**`null` 的含义是「设备这一秒没给这个值」，不是 0。** 逐秒历史 `0x3A` 的
`VitalData_Per_Second` 只有 hr / status / pitch / acc / ppi，没有 bhr、步数、卡路里、rmssd，
这几列在补录秒上一定是 `null`；用 0 顶替会让「步数 0」和「没给步数」混在一起。

`activity` 编码（`status` bit2-0）：

| 值    | 含义                | 属于睡眠 |
| ----- | ------------------- | -------- |
| 0     | 深度睡眠            | 是       |
| 1     | 浅度睡眠            | 是       |
| 2     | 其他睡眠            | 是       |
| 3     | 精神放松            | 否       |
| 4 / 5 | 活动量低 / 活动量高 | 否       |
| 6 / 7 | 精神兴奋 / 身体压力 | 否       |

`behavior` 编码（`status` bit5-3）：

| 值  | 含义     |
| --- | -------- |
| 0   | 休息     |
| 1   | 日常生活 |
| 2   | 步行     |
| 3   | 跑步     |
| 4   | 骑行     |
| 5   | 有氧运动 |
| 6   | 其他运动 |
| 7   | 保留     |

## 2. `/upload/sleep`

```json
{
	"device": "BOOM-0001",
	"address": "AA:BB:CC:DD:EE:FF",
	"timezone": "08:00",
	"datas": [
		{
			"time": "2026-10-08 07:30:00",
			"sleepOnsetTime": 25200,
			"awakeTime": 1800,
			"lightSleepPeriod": 14400,
			"deepSleepPeriod": 7200,
			"otherSleepPeriod": 1800,
			"heartRateRest": 55
		}
	]
}
```

| 字段                                                        | 说明                                                 |
| ----------------------------------------------------------- | ---------------------------------------------------- |
| `time`                                                      | 事件结算时刻（设备时钟），按 `timezone` 格式化       |
| `sleepOnsetTime`                                            | 入睡时刻，**距 `time` 的秒数**（设备原样给的相对值） |
| `awakeTime`                                                 | 醒来时刻，**距 `time` 的秒数**                       |
| `lightSleepPeriod` / `deepSleepPeriod` / `otherSleepPeriod` | 浅睡 / 深睡 / 其他睡眠时长，秒                       |
| `heartRateRest`                                             | 静息心率 bpm                                         |
