A1.0 初始版本

BOOM状态说明
1　功能说明
1.1　运行状态
正常运行时，指示灯长灭。默认蓝牙广播设备名称BOOM-0001。
电池异常：黄色闪烁，每1s闪1次。
充电完成：白色闪烁，每1s闪1次。
短按键，指示灯显示电量，亮5s。电量高：白色；电量中等：蓝色；电量低：品红(紫色)，电量极低：红色。
解绑设备清除数据时：蓝灯快闪。

1.2　开关机
1.2.1　进入休眠
按住按键保持5s，指示灯先由绿色闪烁变为绿色长亮，再变蓝色长亮后，松开按键进入休眠。
1.2.2　唤醒
休眠状态，点按按键松开（按下时间<1s），唤醒。

1.3　通信协议
设备有三类通信场景：
(1)蓝牙自定义广播
(2)蓝牙GATT协议
(3)USB Custom HID协议
根据上面三类场景，定义下面两种通信协议，分别适用不同的通信场景。
1.3.1　蓝牙自定义广播协议
蓝牙自定义广播数据放在Manufacturer Specific Data（AD Type = 0xFF）中，内容包含如下数据结构，字节序：采用小端序（Little-Endian），刷新时间：每秒刷新。
广播数据的内容为custom_adv_data_t格式。

1.3.2　蓝牙GATT协议和USB Custom HID协议
蓝牙GATT协议和USB Custom HID的上下行通信协议格式如下，适合单帧/多帧传输，以组成最大512字节的payload：
字段	长度(字节)	说明
DataIdentifier	2	Bit15:Start Bit
Bit14:End Bit
Bit9 - 13Bit: SquenceNumber
Bit0 - 8Bit:ValidDataNumber
Payload	TLV格式Payload	
注意：若无特殊说明，在蓝牙GATT协议和USB Custom HID的协议说明中只说明payload部分的格式，而在获得payload前必须先根据上表的格式进行解包。

/* @note 协议头定义（2 字节，小端）
 *       - Bit 15: Start Bit（帧起始标志）
 *       - Bit 14: End Bit   （帧结束标志）
 *       - Bit 10~13: SequenceNumber（4 位序列号，0~15）
 *       - Bit 0~9 : ValidDataNumber（vdn, 本帧有效数据字节数，最大 1023）
 * 
 * @note 重组策略：
 *       - 每帧的 vdn 表示本帧携带的有效字节数
 *       - 起始帧重置 recv_index = vdn，非起始帧累加 recv_index += vdn
 *       - 结束帧调用 解包函数
 *       - 总字节数上限受 recv_buf 大小限制（本示例 1024 字节）
 *       - 最多支持 16 帧（4 位序列号）
 */

1.4.4　GATT协议
协议中的Payload采用TLVC格式，按小端存储，格式如下：
字段	长度(字节)	说明
T	2	数据标识，小端存储
L	2	V的长度，小端存储
V		根据T来定义，小端存储
C	2	MODBUS CRC校验小端存储

响应包中，如果长度为0，表示设置或者查询包的格式或者参数有误。

typedef struct {
    /** 
     * Gender.
     * 0 = Male
     * 1 = Female
     * Range: 0 ... 1
     */
    uint8_t gender;   // 偏移 0，1 字节

    /** 
     * 100 times value of weight [kg].
     * Example: 6837 → 68.37 kg
     * Range: 1000 ... 65000
     */
    uint16_t weight;   // 偏移 1，2 字节，小端：低位在前

    /** 
     * 100 times value of height [cm].
     * Example: 17500 → 175.00 cm
     * Range: 10000 ... 28000
     */
    uint16_t height;   // 偏移 3，2 字节，小端：低位在前

    /** 
     * Age [years].
     * Range: 10 ... 99
     */
    uint8_t age;       // 偏移 5，1 字节

    /** 
     * PPG sensor mounting position.
     * 0 = Wrist (手腕)
     * 1 = Forearm (前臂)
     * 2 = Upper arm (上臂)
     * 3 = Head (头部)
     * 4 = Below knee (膝盖下方)
     * 5 = Thigh (大腿)
     * 6 = Body (身体)
     * Range: 0 ... 6
     */
    uint8_t ppg_position;   // 偏移 6，1 字节

    /** 
     * Basal heart rate [bpm].
     * Range: 28 ... 240
     */
    uint8_t bhr;       // 偏移 7，1 字节

} __attribute__((packed)) vital_biometric_info_t;
2.1.2　custom_adv_data_t
自定义广播数据：
typedef struct
{
    /**
     * UTC timestamp [seconds].
     * Unix epoch time (seconds since 1970-01-01 00:00:00 UTC)
     * Range: 0 ... 0xFFFFFFFF
     */
    uint32_t utc; // 偏移 0~3，4字节，小端：低位在前

    /**
     * Battery voltage sampling value [mV].
     * Example: 3870 → 3870 mV = 3.870 V
     * Range: 0 ... 65535 (实际电池范围通常 3000~4200)
     */
    int16_t v; // 偏移 4~5，2字节，小端：低位在前

    /**
     * Status byte combining behavior type and activity status.
     *
     * Bit 7    : Reserved (must be 0)
     * Bit 6    : PPG attachment status
     *            - 0x0 = PPG detached
     *            - 0x1 = PPG attached
     * Bits 5-3 : Behavior type (3 bits, value 0-7)
     *            0x0 = Rest (休息)
     *            0x1 = Daily life (日常生活)
     *            0x2 = Walking (步行)
     *            0x3 = Running (跑步)
     *            0x4 = Cycling (骑行)
     *            0x5 = Aerobic exercise (有氧运动)
     *            0x6 = Other sports (其他运动)
     *            0x7 = Reserved
     * Bits 2-0 : Activity status (3 bits, value 0-7)
     *            0x0 = Deep sleep (深度睡眠)
     *            0x1 = Light sleep (浅度睡眠)
     *            0x2 = Other sleep (其他睡眠)
     *            0x3 = Mental relaxation (精神放松状态)
     *            0x4 = Low activity / ACT- (活动量低)
     *            0x5 = High activity / ACT+ (活动量高)
     *            0x6 = Mental excitement (精神兴奋状态)
     *            0x7 = Physical stress (身体压力)
     */
    uint8_t status; // 偏移 6，1字节

    /**
     * Heart rate [bpm].
     * Range: 0 ... 255 (通常有效范围 30-240)
     */
    uint8_t hr; // 偏移 7，1字节

    /**
     * Pulse to pulse interval [ms].
     * Range: 0 ... 65535
     */
    uint16_t ppi; // 偏移 8~9，2字节，小端：低位在前

    /**
     * Blood oxygen saturation.
     * Range: 700 ... 1000 (表示 70.0% ... 100.0%)
     * Example: 950 → 95.0%
     */
    uint16_t spo2; // 偏移 10~11，2字节，小端：低位在前

    /**
     * Basal heart rate [bpm].
     * Range: 28 ... 240
     */
    uint8_t bhr; // 偏移 12，1字节

    /**
     * Status byte combining behavior type and activity status.
     *
     * Bit 7-4  : 事件递增序号，如果发送改变，需要读一次事件
     * Bits 3-2 : 保留
     * Bits 1-0 : battery status (2 bits, value 0-3)
     *            0x0 = 正常
     *            0x1 = 充电中
     *            0x2 = 充电完成
     *            0x3 = 电池异常
     */
    uint8_t status2; // 偏移 13，1字节

    /** Steps since the 00:00:00 every day. */
    uint32_t steps_everyday; // 偏移 14~17，4字节，小端：低位在前

    /** 100 times value of exercise calorie[kcal] since the 00:00:00 every day. */
    uint16_t calorie_everyday; // 偏移 18~19，4字节，小端：低位在前

    /**
     * RMSSD -
     * Root Mean Square of Successive Differences of
     * [PPI] data [ms].
     */
    float rmssd; // 偏移 20~23，4字节，小端：低位在前

    // 结构体总大小: 24 字节
} __attribute__((packed)) custom_adv_data_t;

2.1.3　VitalData_Per_Second
每秒的生命体征数据
/**
 * @brief  每秒生命体征数据（存储到 Flash 的秒级记录）
 * @note   紧凑打包结构体，按秒记录心率、活动状态、步频、加速度、脉波间期
 */
typedef struct
{
    /**
     * 心率 (Heart Rate) [bpm]
     * 0x00：无效数据
     * 0xFE：空白数据
     * 28-240：有效心率值
     */
    uint8_t heart_rate;     // 偏移 0，1 字节

    /**
     * 复合状态字节
     * Bit[7:6]：保留位 (Reserved)，固定为 0
     * Bit[5:3]：行为类型 (Behavior Type)
     *     0x0：休息 (Rest)
     *     0x1：日常生活 (Daily Life)
     *     0x2：步行 (Walking)
     *     0x3：跑步 (Running)
     *     0x4：骑行 (Cycling)
     *     0x5：有氧运动 (Aerobic Exercise)
     *     0x6：其他运动 (Other Exercise)
     * Bit[2:0]：活动状态 (Activity Status)
     *     0x0：深度睡眠 (Deep Sleep)
     *     0x1：浅度睡眠 (Light Sleep)
     *     0x2：其他睡眠 (Other Sleep)
     *     0x3：精神放松状态 (Mental Relaxation)
     *     0x4：活动量低 (Low Activity, ACT-)
     *     0x5：活动量高 (High Activity, ACT+)
     *     0x6：精神兴奋状态 (Mental Excitement)
     *     0x7：身体压力 (Physical Stress)
     */
    uint8_t status;         // 偏移 1，1 字节

    /**
     * 步频 (Pitch) [步/分钟]
     * 范围：0x00 - 0xFF
     * 超过 255 截断为 255
     */
    uint8_t pitch;          // 偏移 2，1 字节

    /**
     * 加速度幅值 (Acceleration Amplitude)
     * 三轴最大值缩放后的单字节表示
     * 范围：0x00 - 0xFF
     */
    uint8_t acc;            // 偏移 3，1 字节

    /**
     * 脉波间期 (Pulse-to-Pulse Interval, PPI) [ms]
     * 范围：248 - 2504 ms
     * 0 表示无效数据
     * 小端存储：低位在前
     */
    uint16_t ppi;           // 偏移 4，2 字节

} __attribute__((packed)) VitalData_Per_Second;

2.1.4　Log_Data_t

typedef struct

typedef struct

2.1.4.2　eventData数据结构说明
2.1.4.2.1　LogEvent_Text和LogEvent_RemoteCmd和LogEvent_SetDeviceSn
uint8_t eventData[]内容为ascii编码。
2.1.4.2.2　LogEvent_Reset
dataLen = 4
uint8_t eventData[]内容为4字节小端数值，代表重启原因。
2.1.4.2.3　LogEvent_SetTime
dataLen = 8
uint8_t eventData[]内容为两个4字节小端数值，第一个是设置前的时戳，第二个是设置后的时戳。
2.1.4.2.4　LogEvent_FormatDS
dataLen = 4
uint8_t eventData[]内容为4字节小端数值，代表擦除的扇区地址。
2.1.4.2.5　LogEvent_Wear
dataLen = 2
uint8_t eventData[]内容为2个字节，第一个字节表示改变前的状态，第二个字节表示改变后的状态。0表示未佩戴，1表示佩戴。
2.1.4.2.6　LogEvent_SleepResult
dataLen = 22
数据结构如下：
typedef struct {
    uint32_t sleep_onset_time;      // 入睡时刻（距当前秒数）
    uint32_t awake_time;            // 醒来时刻（距当前秒数）

    uint32_t deep_sleep_period;     // 深度睡眠时长（秒）

    uint16_t heart_rate_rest;       // 静息心率（bpm）
} __attribute__((packed)) vital_sleep_result_t;
2.1.4.2.7　LogEvent_Sedentary
dataLen = 2
uint8_t eventData[]内容为2个字节，存放久坐检测阈值时间，单位秒。

dataLen = 8
