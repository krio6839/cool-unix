# BOOM 客户端可靠性回归测试

运行环境：Node.js 22.18 或更高版本，无需新增 npm 依赖。

```sh
npm run test:boom
```

测试通过 Node 的 TypeScript 类型擦除执行实际客户端源码，使用内存 SQLite 验证 SQL、入库和上传标记；模拟原生蓝牙、网络、时钟等待及 App 状态边界。不会连接真实设备或后端，不读取用户数据库。

覆盖两分钟反向读取、全 FF 与零值判定、持久任务与断点恢复、最新窗口滚动、区间合并、设备跳跃待确认、页面事务回滚与并发隔离、时间预算暂停、自动循环恢复、严格上传确认、分批上传、失败重试，以及登录凭证过期和刷新失败。Node 22 的 SQLite 和类型擦除可能打印实验性 API 提示。

这套测试不替代 HBuilderX 的 UTS 原生编译与 Android/iOS 真机验证。发布前需在真机确认断网恢复、后台回前台、GATT 中断后的补拉与上传行为。
